
# Sprint 01 : Cadrage & préparation

## 1. Description du sprint
Sprint de cadrage initial du projet Pharmgreen : analyse des besoins métiers, définition du plan d'adressage IP, élaboration du schéma d'architecture réseau cible, et mise en place du dépôt GitHub servant de support documentaire à l'ensemble du projet.

## 2. Objectifs
Poser les bases documentaires et organisationnelles indispensables avant tout déploiement technique, et disposer d'un référentiel clair pour les 9 sprints suivants.

## 3. Comment
- Étude du fichier RH (`ListeRH.csv`) : 211 employés répartis sur 11 départements
- Définition du plan d'adressage IP : LAN 172.16.10.0/24, DMZ 172.16.20.0/24
- Élaboration du schéma d'architecture réseau cible (zones, VM, flux)
- Création et structuration du dépôt GitHub (`TSSR-0226-P3-G7`) : arborescence `PHARMGREEN/` avec 4 dossiers principaux `01-Architecture/`,`02-Components/`,`03-Operationss/`, `04-Sprints/` et sous-dossiers. 

## 4. Résultats
- Dépôt GitHub opérationnel et structuré
- Plan d'adressage IP validé et appliqué dans l'ensemble des sprints suivants
- Schéma d'architecture de référence disponible pour la suite du projet
